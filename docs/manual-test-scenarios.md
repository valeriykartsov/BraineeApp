# BraineeApp — ручные сценарии проверки

Документ для ручной проверки приложения. Написан простым языком: что видит пользователь и что должен сделать.

**Как пользоваться:** идите по сценариям сверху вниз. Для каждого отметьте: ✅ работает / ❌ баг (с кратким описанием). Автотесты и отладочные флаги симулятора — в [`TESTING.md`](TESTING.md).

---

## 0. Запуск приложения

### 0.1 Первый запуск (или после полной очистки данных)
1. Открыть приложение.
2. На ~1 секунду виден экран с логотипом, названием **BraineeApp** и текстом **Make your day!**
3. Затем открываются вкладки: **Задачи**, **Календарь**, **Профиль** (вкладки LLM по умолчанию нет).

**Ожидание:** нет экрана «Ошибка загрузки», вкладки переключаются.

### 0.2 Повторный запуск с уже сохранёнными данными
1. Создать задачу (см. сценарий 1.1).
2. Полностью закрыть приложение и открыть снова.

**Ожидание:** задача на месте, название и настройки не пропали.

### 0.3 Ошибка загрузки (редко)
Если данные повреждены и не читаются — экран **«Ошибка загрузки»** с текстом ошибки.

## 1. Раздел «Задачи»

Единый список всех задач (бывшие Карьера / Спорт / Ментальное после обновления сливаются сюда).

### 1.0 Миграция со старых разделов
1. Если до обновления были задачи в Карьере / Спорте / Ментальном — открыть приложение после обновления.

**Ожидание:** все задачи и папки видны во вкладке **Задачи**; поле «Тип» в форме задачи отсутствует.

### 1.1 Создать задачу
1. Открыть **Задачи** → нажать **+**.
2. Ввести название, нажать **Сохранить**.

**Ожидание:** задача появилась в списке со статусом **Новая**. Поля **Статус** в форме создания нет. Кнопка **Сохранить** неактивна, пока название пустое (или только пробелы).

### 1.2 Создать задачу со всеми полями
1. **+** → название, описание; открыть **Дата** → выбрать → **ОК** (или **Сброс**); при необходимости **Время** → **ОК** / **Сброс**.
2. В **Напоминание** выбрать пресет как в Календаре (например «За 1 час»); при желании **Добавить уведомление** (до 3); приоритет, теги.
3. **Сохранить**.

**Ожидание:** в строке задачи видны название, описание, дата (и время — только если выбрано), приоритет и теги. Пуши по выбранным пресетам работают, если в Уведомлениях включены «Разрешить» и «При приближении». ОК/Отмена при вводе — только над клавиатурой.

### 1.2a Распознавание в названии (п. 46)
1. **+** → в «Название» ввести «завтра в 10:30 купить хлеб #» — над клавиатурой подсказки тегов; выбрать тег; дописать «!» — подсказки приоритетов, выбрать «!высокий».
2. Вручную сменить дату в форме на другую и дописать к названию ещё слово.
3. **Сохранить**. Затем открыть эту задачу на редактирование и дописать «25.10».
4. «+» во вкладке «Календарь» — ввести «#незнакомый тег 31.02».

**Ожидание:** на шаге 1 сразу заполнены срок (завтра, 10:30), тег и приоритет «Высокий». На шаге 2 дата не возвращается к «завтра». Сохраняется название «купить хлеб» — без меток. При редактировании распознавания нет: «25.10» остаётся в названии. На шаге 4 незнакомый тег и несуществующая дата остаются текстом. Сеть не нужна.

### 1.3 Редактировать задачу
1. Нажать на задачу (или долгий тап → **Редактировать**).
2. Изменить название / статус (над дедлайном) / дату / время / приоритет / описание.
3. **Сохранить**.

**Ожидание:** форма в стиле других разделов (карточки-группы); статус выше дедлайна; изменения видны в списке. Ввод названия/описания без подвисаний.

### 1.3a Тап по пушу открывает задачу
1. Создать задачу с дедлайном и напоминанием (или дождаться пуша о приближении / просрочке).
2. Когда придёт пуш по задаче — нажать на него.

**Ожидание:** открывается вкладка **Задачи** и карточка этой задачи.

### 1.3b Отмена описания и карточки
1. Открыть задачу → в описании изменить текст → **Отмена** над клавиатурой → в алерте **Сбросить**.
2. Без изменений в поле **Отмена** неактивна; после **ОК** над клавиатурой текущий текст фиксируется — дальнейшая **Отмена** снова неактивна, пока не измените поле.
3. Снова изменить любое поле → **Отмена** всей карточки (в навбаре).

**Ожидание:** (1) после подтверждения описание вернулось к тексту после открытия формы / последнего **ОК**; (2) предупреждение о несохранённых изменениях — можно вернуться или закрыть без сохранения.

### 1.3d Виджеты
1. На домашнем экране iOS: **Добавить виджет** → BraineeApp.
2. Доступны 4 виджета: **Задачи сегодня** (S), **Привычки** (S), **Задачи и дашборд** (M), **Задачи и привычки** (L).
3. Нажать на виджет.

**Ожидание:** виджеты показывают актуальные данные после работы в приложении; тап открывает BraineeApp.

### 1.3e Виджеты экрана блокировки
1. Подготовить: 3 задачи с дедлайном сегодня (1 выполнить), 1 просроченную, 2 привычки (1 отметить).
2. Экран блокировки → долгое нажатие → **Настроить** → экран блокировки → поле виджетов → BraineeApp: добавить **Календарь** (1×1) и **Сегодня** (2×1).
3. Проверить содержимое, затем в приложении выполнить ещё одну задачу и заблокировать iPhone.
4. В приложении открыть вкладку «Календарь», выбрать другой день, заблокировать iPhone, нажать на любой из двух виджетов.
5. Скрыть вкладку «Календарь» в настройках и снова нажать на виджет.

**Ожидание:** «Календарь» — день недели, число, под ними «2/3» (осталось/всего, просроченная не считается), после шага 3 — «1/3». «Сегодня» — «Привычки 1 из 2», «Задачи ещё 2 из 3» с полосками, после шага 3 — «ещё 1 из 3». Цвет — системный (одноцветный), текст не обрезан. Нажатие открывает «Календарь» на **сегодняшнем** дне; со скрытой вкладкой — «Задачи». Утром, до открытия приложения, — новая дата, у задач «—», привычки «0 из 2».

### 1.3c Просрочка по времени
1. Создать задачу с дедлайном **сегодня** и временем, которое уже прошло.
2. Посмотреть строку задачи в списке.

**Ожидание:** дата/время дедлайна красные; строка задачи на бледно-красном фоне. Без времени — просрочка только со следующего дня.

### 1.4 Список по умолчанию после смены вкладки
1. В **Задачах** переключить вид на **Канбан**.
2. Открыть **Профиль** (или другой раздел), затем снова **Задачи**.

**Ожидание:** снова открыт вид **Список**.

### 1.5 Отметить выполненной
1. Нажать кружок слева от задачи.

**Ожидание:** задача отмечена выполненной, уезжает **вниз** своей группы (или «Входящих»); при отметке есть лёгкая вибрация. Снять галочку — задача встаёт в конец незакрытых.

### 1.5a Карточка задачи (п. 37)
1. Список, канбан, вкладка «Календарь», квадрант матрицы: нажать на карточку (не на кружок и не на корзину).
2. Долго удержать карточку в «Календаре» и в матрице; провести по карточке справа налево в списке.

**Ожидание:**
- нажатие открывает форму задачи; «карандаша» нет, справа только корзина;
- название в одну строку с «…», описание не длиннее 2 строк;
- под описанием метки по порядку: срок, статус, приоритет, до 3 тегов, «☑ 1/2» последним; не поместившаяся метка переносится на следующую строку (в канбане — тоже), очень длинный тег обрезается «…» и не выходит за край карточки;
- у всех карточек одинаковые отступы, высота — по содержимому; у просроченной красный фон, а размер и положение текста такие же, как у обычной;
- долгое удержание не открывает меню (в «Календаре» и матрице ничего не происходит), свайпа удаления нет.

### 1.6 Мягкое удаление из списка
1. Нажать корзину на карточке → **Удалить задачу?** → **Отмена**: задача на месте.
2. Ещё раз корзина → **Удалить**.
3. Повторить в канбане, «Календаре» и матрице.

**Ожидание:** без подтверждения ничего не удаляется; после подтверждения задача пропала из раздела; в **Профиль → Дополнительно → Удалённые задачи** она есть.

### 1.6a Свернуть / развернуть все группы
1. В **Задачи → Список** слева от настроек отображения нажать анимированную стрелку.
2. Если часть групп открыта — стрелка «развернуть» открывает оставшиеся.
3. Если все открыты — стрелка «свернуть» закрывает группы (уже закрытые не меняются).

**Ожидание:** группы синхронно раскрываются/сворачиваются; стрелка поворачивается.

### 1.7 Мягкое удаление из формы
1. Открыть задачу → **Удалить задачу** → подтвердить.
2. Текст подтверждения: задача будет перемещена в «Удалённые задачи» в профиле.

**Ожидание:** то же, что в 1.6.

### 1.8 Режимы «По дате» и «План на день»
1. Переключатель **Режим**: **По дате** / **План на день**.
2. Создать задачу с дедлайном **сегодня** и задачу с дедлайном **завтра**.

**Ожидание:**
- **По дате** — видны обе (и задачи без даты).
- **План на день** — только задачи на сегодня.

### 1.9 Пустой «План на день»
1. Убедиться, что нет задач с дедлайном на сегодня и нет групп (или все группы пустые на сегодня).

**Ожидание:** текст **«План на день пуст»** / **«Добавьте задачи с дедлайном на сегодня»**.

### 1.10 Просроченная задача
1. Создать задачу с датой **вчера** (или раньше).

**Ожидание:** дата в списке красная, строка на бледно-красном фоне; в дашборде профиля растёт счётчик **Просрочено**. Выполненная задача с прошедшей датой **не** считается просроченной.

## 2. Группы (папки)

### 2.1 Создать группу
1. Нажать иконку папки с плюсом → ввести название → **Создать**.

**Ожидание:** папка появилась в списке **Задачи**.

### 2.2 Пустое название группы
1. Открыть создание группы, оставить поле пустым (или пробелы) → **Создать**.

**Ожидание:** группа **не** создаётся (без отдельного сообщения об ошибке).

### 2.3 Перетащить задачу в группу
1. Режим **По дате**.
2. Долго удержать карточку задачи (ручки «три полоски» больше нет), потянуть и бросить в папку.

**Ожидание:** задача оказалась внутри папки.

### 2.4 Перетащить задачу во «Входящие»
1. Перетащить задачу из папки в блок **Входящие**.

**Ожидание:** задача вне папок, в блоке «Входящие».

### 2.4a Перетаскивание на длинном списке (ленивый список, п. 10)
1. Нужно много задач (в Debug — запуск с `-SeedDemoData -DemoTaskCount 300`).
2. Прокрутить список вверх-вниз быстрыми жестами.
3. Перетащить задачу из первой папки в последнюю (список прокручивается сам у края экрана) и обратно во «Входящие».
4. Быстро провести пальцем по карточке вверх-вниз и коротко нажать на карточку.

**Ожидание:** прокрутка без заметных рывков; во время перетаскивания папки, появившиеся при прокрутке, подсвечиваются рамкой и принимают задачу; вертикальная прокрутка, начатая на карточке, не «залипает» и не начинает перенос; короткое нажатие открывает форму, а не перенос.

### 2.5 Удалить группу
1. Нажать корзину у папки.

**Ожидание:** папка исчезла; задачи из неё **не удалились**, а перешли во **Входящие**.

### 2.6 Удалить последнюю задачу из папки
1. В режиме **Список** удалить (мягко) все задачи из папки.

**Ожидание:** папка остаётся пустой с подсказкой «Перетащите в …».

### 2.7 Свернуть / развернуть группу
1. В группе с задачами нажать шеврон слева от папки.
2. Нажать снова — список задач раскрывается.
3. У пустой группы шеврон неактивен.

**Ожидание:** задачи скрываются и снова показываются; у пустой группы кнопка disabled.

### 2.8 Канбан — выравнивание
1. Переключить вид на **Канбан**.

**Ожидание:** колонки начинаются на той же высоте, что и карточки списка; левый край совпадает с отступами экрана. Сортировка — в меню иконки ↑↓ справа.

### 2.9 Канбан — карточка и перенос (п. 38)
1. Вид **Канбан**. Посмотреть карточку с описанием, несколькими тегами и подзадачами и просроченную карточку.
2. Долго удержать карточку и перенести в другую колонку; прокрутить колонку вверх-вниз, начиная жест на карточке; коротко нажать на карточку.

**Ожидание:** карточка такая же, как в списке: название в 1 строку, описание до 2 строк, метки переносятся внутри колонки, ручки «≡» и «карандаша» нет; у просроченной красится вся карточка, размер тот же. Перенос меняет статус задачи; прокрутка не начинает перенос; короткое нажатие открывает форму.

### 2.10 Канбан по папкам (п. 44)
1. Вид **Канбан** → «Настройка отображения»: есть «Разбить по папкам» (выключено), нет «Показывать выполненные». Включить.
2. Прокрутить экран вверх-вниз, начиная жест на карточке; прокрутить ряд колонок одной доски вбок.
3. Долго удержать карточку и перенести в другую колонку той же доски; затем — в колонку другой доски.
4. Свернуть доску шевроном; переключиться на **Список**; нажать «Свернуть / развернуть все» в канбане.
5. Выключить настройку.

**Ожидание:** доски только у папок с задачами, по порядку папок, «Входящие» — последней и без шеврона; у заголовка счётчик задач. Колонки по высоте содержимого. Прокрутки не мешают друг другу и не начинают перенос. Перенос внутри доски меняет статус; в колонку другой доски карточка не принимается, папка не меняется. Свёрнутая папка свёрнута и в списке, «все» сворачивает/разворачивает доски. После выключения — одна доска, как раньше. В журнале сессии — «Канбан по папкам».

## 3. Профиль

### 3.1 Редактирование профиля
1. Открыть **Профиль** → блок **Пользователь** → карандаш / «Редактировать».
2. Задать имя, возраст, пол; при желании — фото.
3. Подтвердить сохранение.

**Ожидание:** имя, возраст и пол видны в блоке пользователя; после перезапуска остаются.

### 3.1a Статус профиля (п. 35, D-45)
1. «Изменить профиль» → поле «Статус» (под «Пол») → вставить текст длиннее 60 символов → **Сохранить** → подтвердить.
2. Снова открыть, стереть статус, сохранить.
3. С непустым статусом: «Профиль → Хранение данных» → экспорт; сменить статус; восстановить из экспортированного файла.

**Ожидание:** счётчик не превышает «60/60», лишнее отрезается. Статус — под именем курсивом, одна строка, длинный обрезается «…». Пустой статус не показывается. В «Журнале сессии» — «Профиль изменён: Статус изменён» без текста статуса. После восстановления — статус из файла. Статуса нет в чате LLM, виджетах и тексте «Поделиться».

### 3.1b Открытый подраздел сохраняется (п. 41)
1. «Профиль → Настройки → Тема оформления»; свернуть приложение и вернуться.
2. Переключиться на «Задачи» и обратно на «Профиль».
3. Открыть поиск настроек, ввести «тема», переключить вкладку и вернуться.
4. Нажать на вкладку «Профиль» ещё раз.
5. Открыть «Матрицу Эйзенхауэра» (лист), свернуть приложение, нажать на уведомление о задаче.

**Ожидание:** в шагах 1–3 открыт тот же экран, поиск с текстом остаётся. В шаге 4 — корень «Профиля», поиск закрыт. В шаге 5 лист «Матрицы» закрывается, открывается задача во вкладке «Задачи»; при возврате в «Профиль» — тот же подраздел, что был под листом.

### 3.1c Помодоро (п. 47, D-47)
1. «Профиль → Дополнительно → Помодоро» (под «Матрицей»), режим «25 / 5» → **Старт**. Свернуть приложение.
2. Посмотреть Dynamic Island и экран блокировки; нажать на карточку.
3. Дождаться конца фокуса со свёрнутым приложением (для проверки — подождать 25 мин или перевести часы).
4. Открыть приложение; «Журнал сессии».
5. **Стоп**.

**Ожидание:** в Dynamic Island — логотип и отсчёт, на экране блокировки — «Фокус 25 мин · до ЧЧ:ММ» и отсчёт, кнопок нет; нажатие открывает экран Помодоро. На смене — уведомление со звуком «Фокус 25 мин завершён — перерыв 5 мин»; карточка без приложения показывает «Фокус окончен · перерыв до …», после открытия — «Перерыв 5 мин» с отсчётом. В журнале — «Помодоро: фокус 25 мин завершён». После «Стоп» карточка и будущие уведомления исчезают. Режим нельзя сменить, пока таймер идёт; через 8 часов таймер останавливается сам (последнее уведомление «Помодоро завершено: прошло 8 часов»).

### 3.2 Аватар
1. В редактировании профиля выбрать картинку из галереи (или сменить существующую).

**Ожидание:** аватар отображается в профиле; после перезапуска на месте.

### 3.2b Уведомления
1. При первой установке система показывает запрос разрешения на уведомления.
2. **Профиль → Настройки → Уведомления** (под **Тема оформления**).
3. Блок **Наклейка на иконке**: выбрать **Выкл** / **Просроченные** (по умолчанию) / **Сегодня и просроченные**.
4. Свитчер **Разрешить уведомления** выкл — блоков Задачи/Привычки/Дедлайн нет; наклейка настраивается отдельно.
5. Включить уведомления — секция **Использование приложения**: напоминания о задачах и привычках, у каждого своё время (по умолчанию задачи 10:00, привычки 09:00); плюс блок **Дедлайн** (приближение / просрочка).
6. В настройках iOS → BraineeApp должны быть уведомления приложения (для красного кружка на иконке нужны «Наклейки»).

**Ожидание:** разрешение запрашивается; настройки сохраняются; при отказе в системе есть кнопка открыть настройки устройства. Счётчик на вкладке **Задачи** совпадает с режимом наклейки; на Home Screen — красный кружок с тем же числом (если iOS разрешил badge).

### 3.2d Кнопки в уведомлении о задаче (п. 45, D-46)
1. Задача со временем через 1–2 минуты и пресетом напоминания «в момент срока» (или просроченная — уведомление в 11:00). Свернуть приложение, дождаться уведомления, потянуть его вниз (долгое нажатие).
2. Нажать **Напомнить через час**; затем изменить любую другую задачу в приложении и снова свернуть.
3. На следующем уведомлении задачи — **На завтра** (телефон заблокирован — сначала разблокировать).
4. На другом уведомлении задачи — **Выполнено**. Посмотреть приложение, «Журнал сессии», виджет, наклейку и Календарь «BraineeApp».
5. Общее напоминание «Задачи» / «Привычки».

**Ожидание:** у уведомления задачи три кнопки, приложение не открывается. Через час то же уведомление приходит снова, срок не изменился; повтор не пропадает после изменения другой задачи. «На завтра» — срок завтра в то же время (без времени — без времени). «Выполнено» — задача «Готово», наклейка и виджет обновлены, событие в Календаре убрано, «просрочено» по ней не приходит. В журнале — «… (из уведомления)», если приложение не выгружалось. У общих напоминаний кнопок нет.

### 3.2c Наклейка: просроченные
1. Создать незакрытую задачу с дедлайном **вчера**.
2. Режим наклейки — **Просроченные**.
3. Посмотреть вкладку **Задачи** и иконку на Home Screen.

**Ожидание:** счётчик ≥ 1. Выполнить задачу или сменить режим на **Выкл** — счётчик пропадает / обнуляется.

### 3.3 Тема оформления
1. **Профиль → Настройки → Тема оформления**.
2. Выбрать **Системная** / **Светлая** / **Тёмная**.
3. Открыть **Акцентный цвет**, выбрать цвет → **Готово**.
4. Проверить свитчер **Зафиксировать положение** (по умолчанию вкл): при включении экран только вертикальный; выключить — можно повернуть горизонтально. Настройка важнее системного автоповорота.

**Ожидание:** тема и акцент меняются сразу; после перезапуска сохраняются. Ориентация следует свитчеру.

### 3.3a Акцентный цвет и иконка приложения
1. **Профиль → Настройки → Тема оформления → Акцентный цвет** → выбрать другой цвет (в т.ч. **Кислотно-зелёный**) → **Готово**.
2. Подтвердить системное окно iOS о смене иконки (если появится). Своего окна приложения быть не должно.
3. Выйти на домашний экран и посмотреть иконку BraineeApp.

**Ожидание:** средняя полоска на иконке того же цвета, что выбранный акцент; кнопки и прогресс в приложении тоже в этом цвете. Оранжевый возвращает основную иконку.

### 3.3c Свой фон (п. 58, D-48)
1. «Профиль → Настройки → Тема оформления → Фон» → «Выбрать картинку», выбрать фото.
2. Пройти по вкладкам «Задачи» (список и канбан), «Календарь», «LLM», «Привычки», «Профиль», открыть настройки, журнал, Помодоро, матрицу, корзину.
3. Открыть задачу, «+», «Изменить профиль», привычку.
4. Подвигать «Затемнение», включить «Размытие», переключить тему светлая/тёмная.
4a. С картинкой во вкладке «Задачи» нажать «Список / Канбан», «свернуть / развернуть папки», «добавить папку», «добавить задачу», «настройки отображения», свернуть одну папку; в «Календаре» — кнопки шапки и «+».
5. «Без фона», затем снова «Картинка». «Удалить картинку» → «Удалить».
6. Сделать ручной бэкап и восстановить его при выбранной картинке.

**Ожидание:** после шага 1 режим сам становится «Картинка», в превью — выбранное фото. На шаге 2 картинка под всеми экранами, без стыков между заголовком и списком; карточки и панель вкладок непрозрачные, текст читается; шапка «Профиля» (логотип, название, поиск) — прямо на картинке, без отдельной полосы, как в других вкладках. На шаге 3 формы однотонные. На шаге 4 затемнение меняется сразу, тема меняет цвет слоя и элементов, картинка та же. На шаге 4a все кнопки откликаются с первого нажатия (п. 59). На шаге 5 «Без фона» — однотонный фон, «Картинка» возвращает то же фото; после удаления — однотонный фон, кнопки «Удалить картинку» нет. На шаге 6 размер бэкапа не вырос, после восстановления фон тот же. В «Журнале сессии» — «Фон», «Затемнение фона», «Размытие фона», «Картинка фона: Выбрана / Удалена». Виджеты и Dynamic Island — без фона.

### 3.3d Стекло и панель-капсула (п. 60)
1. Без картинки фона: посмотреть панель вкладок, открыть «Тема оформления → Стекло».
2. Выбрать картинку фона, включить «Стекло». Пройти по вкладкам; в «Задачах» нажать все кнопки шапки и переключить «Список / Канбан».
3. «Прозрачность элементов»: 0 %, 50 %, 100 %. Открыть задачу, «+», «Изменить профиль», матрицу.
4. Прокрутить длинный список задач до конца. В чате LLM открыть клавиатуру.
5. Включить в настройках iPhone «Универсальный доступ → Дисплей и размер текста → Понижение прозрачности». Затем выбрать «Без фона».

**Ожидание:** на шаге 1 панель — сплошная плавающая капсула, переключатель «Стекло» недоступен с пояснением. На шаге 2 кнопки шапок, сегмент, капсула и панель ввода чата стеклянные; все кнопки откликаются. На шаге 3 при 0 % карточки как без стекла, при 50–100 % через них видна картинка, текст читается; формы и матрица-лист: формы однотонные, матрица — со стеклом. На шаге 4 список прокручивается под капсулой, но докручивается до конца так, что последняя задача встаёт над капсулой (п. 61); при старте содержимое стоит под шапкой, при прокрутке уходит под неё и размывается, кнопки шапки нажимаются — так же в «Календаре», «Привычках», «Профиле», чате LLM; поле чата стоит прямо над клавиатурой, капсула — под клавиатурой. На шаге 5 стекло пропадает (сплошные элементы), «Без фона» — стекла нет, переключатель недоступен. В «Журнале сессии» — «Стекло», «Прозрачность элементов».

### 3.3b Первая установка — акцент оранжевый
1. Удалить приложение с устройства и установить заново (или первый запуск).

**Ожидание:** акцентный цвет **Оранжевый**, основная иконка — даже если раньше выбирали другой цвет.

### 3.4 Дашборд
1. В профиле посмотреть секцию **Дашборд**.

**Ожидание:** один блок **Все задачи**: выполнено/всего, прогресс, счётчики **Активные**, **Просрочено**, **Сегодня**. Удалённые задачи в дашборд **не** входят.

### 3.4b Детализация дашборда
1. Нажать на блок **Все задачи** → открывается **Дашборд**.
2. Наверху переключатель **Активные / Все**; ниже **Сводка**, **Доли тегов** (круговая диаграмма и легенда: тег, число задач, %), **По приоритетам**, **По тегам**.
3. Переключить на **Все**.

**Ожидание:** в «Активных» удалённых задач нет. В «Всех» цифры и диаграмма учитывают корзину, в сводке появляется **В корзине N**, у удалённых задач в списках подпись **В корзине**. В каждой группе «По приоритетам» и «По тегам» сначала актуальные (новые, в работе), ниже выполненные, ещё ниже — в корзине; внутри каждой части — по названию (п. 42). Задача с двумя тегами учитывается в обоих секторах; проценты в легенде в сумме дают 100. При повторном открытии экран снова на **Активных**.

### 3.4a Панель вкладок
1. **Профиль → Настройки → Панель вкладок**.
2. Включить **LLM** и **Привычки**; при желании выключить **Календарь**.

**Ожидание:** порядок вкладок **Задачи → Календарь → LLM → Привычки → Профиль** (отключённые пропускаются). Задачи и Профиль — «Всегда». Календарь / LLM / Привычки — тумблеры с анимацией в меню.

**Обновление со старой версии (NAV-1):** если раньше была включена вкладка «Матрица», на её месте сразу видна **LLM**; если была выключена — LLM тоже выключена.
3. Выключить опциональную вкладку, на которой находитесь.

**Ожидание:** вкладка исчезает; открывается **Задачи**.

### 3.5 Пустой профиль
1. При первом заходе имя может быть пустым, аватар — заглушка.

**Ожидание:** приложение не падает.

## 6. Сохранение данных (критично)

### 6.1 Сохранение после создания / правки
1. Создать или изменить задачу, группу, тег, имя, тему.
2. Свернуть приложение или перезапустить.

**Ожидание:** всё на месте. Данные хранятся в SwiftData (`Application Support/BraineeApp/BraineeApp.store`); при сворачивании раз в сутки появляется автобэкап в `Application Support/Backups/auto/`.

### 6.2 Мягкое удаление переживает перезапуск
1. Удалить задачу мягко → перезапустить → открыть «Удалённые».

**Ожидание:** удалённая задача всё ещё там.

### 6.3 Восстановление из резервной копии
1. Профиль → Хранение данных → «Экспорт резервной копии» → сохранить в «Файлы».
2. Удалить или изменить задачу.
3. «Восстановить из резервной копии» → выбрать файл → проверить предпросмотр → «Заменить данные».

**Ожидание:** данные как в файле; аватар прежний; в сообщении — имя файла `pre-restore-…json` с состоянием до замены. После удаления и переустановки приложения данные **не** возвращаются сами (D-02) — только так, из файла.

## 7. Граничные случаи и валидация

| № | Ситуация | Ожидание |
|---|----------|----------|
| G1 | Название задачи пустое или из пробелов | **Сохранить** недоступна / задача не создаётся |
| G2 | Описание ровно 200 символов | Сохраняется; счётчик `200/200` |
| G3 | Попытка ввести больше 200 символов в описание | Ввод ограничивается на экране |
| G4 | Задача без дедлайна | В режиме «По дате» в конце списка (после задач с датами) |
| G5 | Только пробелы в названии группы/тега | Не создаётся |
| G6 | Дубликат тега (без учёта регистра) | Не создаётся |
| G7 | Удаление последней задачи в разделе | Список пустой / пустая папка, без краша |
| G8 | Удаление последней группы | Остаются «Входящие», задачи живы |
| G9 | Удаление последнего тега | «Нет тегов», в форме нет секции тегов |
| G10 | Удаление последней записи в «Удалённых» | Пустая папка |
| G11 | Перетаскивание уже удалённой задачи | Не должно срабатывать (её нет в активном списке) |
| G12 | Просроченная + выполненная | Не считается просроченной |
| G13 | Дашборд при нуле задач | 0/0, прогресс 0, без деления на ноль / краша |
| G14 | Старый файл данных без поля `isDeleted` | Приложение открывается, задачи как активные |
| G15 | Имя профиля пустое | Допустимо |

## 9. Календарь

### 9.1 Неделя и день
1. Открыть **Календарь**.
2. Стрелками сменить неделю; тапнуть по дню.

**Ожидание:** полоса из 7 дней; выбранный день подсвечен; заголовок периода обновляется.

### 9.2 Задачи дня
1. Создать в **Задачах** задачу с дедлайном на выбранный день.
2. Открыть этот день в календаре.

**Ожидание:** задача в списке «Задачи дня». Задачи без дедлайна в календарь не попадают.

### 9.3 Пустой день
1. Выбрать день без задач.

**Ожидание:** «На этот день задач нет» и подсказка «Нажмите «+», чтобы добавить задачу на этот день».

### 9.4 «+» — задача на выбранный день (п. 40)
1. Выбрать день на следующей неделе → «+» справа от «Поделиться».
2. Ввести название → **Сохранить**.
3. Выбрать вчерашний день → «+» → название → **Сохранить**.

1. Режим «Разбор» → вставить 4–5 дел одним текстом → отправить; сохранить два черновика.

### 13.5a Матрица (D-42)

1. Открыть задачу → раздел «Подзадачи» → «Добавить подзадачу», ввести «Коробки», Return, ввести «Грузчики», Return в новой пустой строке.
2. Отметить «Коробки», «Сохранить». В списке задач посмотреть строку задачи.
3. Снова открыть задачу: изменить текст «Грузчики», удалить «Коробки», добавить строку с пробелами; «Отмена» → «Закрыть без сохранения». Открыть ещё раз.
4. Добавлять подзадачи до 10; ввести текст длиннее 50 символов.
5. Отметить все подзадачи, сохранить.
6. «Задачи → настройки отображения» выключить «Подзадачи».
7. Нажать «Добавить подзадачу» и, не вводя текст, сразу нажать крестик у новой пустой строки; то же — у заполненной строки, пока в ней курсор.

**Ожидание:** на шаге 1 Return переводит на новую строку, Return в пустой строке закрывает клавиатуру. На шаге 2 в строке задачи (список, канбан, «Календарь», матрица) — «☑ 1/2». На шаге 3 после «Отмены» всё как после шага 2. На шаге 4 после 10-й подзадачи вместо кнопки — «Не больше 10 подзадач», текст обрывается на 50-м символе; строки из пробелов при сохранении исчезают. На шаге 5 задача остаётся невыполненной, счётчик «☑ 2/2». На шаге 6 счётчик пропадает. На шаге 7 строка удаляется, приложение не падает (п. 62). В «Журнале сессии» — «Подзадачи: +2, отмечено 1» и т. п. (только числа, без текста). В Календаре iPhone, чате LLM, виджетах и тексте «Поделиться» подзадач нет.

## 17. Панель вкладок и клавиатура (п. 57)

### 17.1 Сохранение задачи с открытой клавиатурой (iPhone)
1. «Задачи» → открыть любую задачу → нажать на название (открылась клавиатура с «Отмена / ОК») → «Сохранить».
2. Свернуть приложение, вернуться.
3. То же из вкладки «Календарь»; то же с «Отмена» и с новой задачей через «+».

**Ожидание:** после закрытия формы клавиатуры нет; после возврата панель вкладок внизу, без пустой полосы под ней.

### 17.2 Смена вкладки с открытой клавиатурой
1. «LLM» → нажать на поле ввода (клавиатура открылась).
2. Не закрывая клавиатуру, нажать «Задачи».
3. Вернуться в «LLM», снова нажать на поле, свернуть приложение и вернуться.

**Ожидание:** на шаге 1 поле ввода чата стоит прямо над клавиатурой, панель вкладок — под клавиатурой (не поднимается). На шаге 2 клавиатура закрывается, «Задачи» без пустой полосы. На шаге 3 после возврата клавиатуры нет, панель внизу.
